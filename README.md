# Needle

YouTube 영상과 재생목록을 전체 창 배경으로 재생하는 다크톤 플레이어입니다. macOS 14 이상을 대상으로 합니다. 링크 재생에는 API 키가 필요 없고, Google 로그인을 지원하는 배포본에는 개발자가 OAuth 설정을 포함합니다. 외부 패키지나 별도 서버는 사용하지 않습니다.

기본 창은 약 520×900px의 세로형 레이아웃이며, 배경 영상은 중앙을 기준으로 좌우를 크롭합니다.

## macOS 실행

```sh
./build-macos.sh
open Needle.app
```

- 일반 YouTube, YouTube Music, Shorts, Live, 재생목록 링크를 지원합니다.
- 마지막으로 불러온 재생목록을 기기에 저장하고 다음 실행 때 자동으로 복원합니다.
- 북마크 메뉴에서 재생목록을 4개 슬롯에 저장하고 다시 불러오거나 삭제할 수 있습니다.
- 저장된 목록은 링크 입력란에 `playlist1: 재생목록 이름` 형식으로 표시되며, 중첩 메뉴 없이 슬롯 4개가 바로 나타납니다.
- 재생 중인 YouTube 재생목록은 30초마다 변경 여부를 확인하고 현재 곡을 유지한 채 자동 갱신합니다.
- 재생목록을 불러오면 하단에 영상 썸네일 큐가 나타납니다.
- 이전/다음 버튼은 재생목록 영상을 이동하고, 단일 영상에서는 ±10초를 이동합니다.
- 진행 바를 클릭하거나 좌우로 드래그하면 즉시 해당 위치로 이동합니다. 일시정지 상태에서도 탐색할 수 있으며 VoiceOver 증감 조작은 5초씩 이동합니다.
- 영상은 창 전체 배경에서 재생되며 제목, 채널, 시간과 컨트롤이 오버레이됩니다.
- 중앙 바이닐은 재생 중 회전하며 레코드 중앙에 현재 YouTube 채널 이미지를 표시합니다.
- 재생목록 큐는 현재/다음/재생 완료 상태, 순서와 전체 진행률을 함께 표시합니다.
- 큐 썸네일은 제목 없이 순서만 표시하며, 카드를 다른 카드 위로 드래그해 재생 순서를 바꿀 수 있습니다.
- 좌우 이동 버튼과 가로 스크롤로 창 밖의 마지막 영상까지 확인할 수 있습니다.
- 반복 버튼 하나로 반복 끔, 한 곡 반복, 전곡 반복을 전환하며 셔플 재생도 지원합니다.
- 한 곡 반복은 곡이 끝나면 같은 영상을 처음부터 다시 재생합니다. 이 상태에서도 이전/다음 버튼은 다른 곡으로 이동합니다. 반복 끔에서는 마지막 곡 뒤 멈추며, 전곡 반복에서는 처음으로 돌아갑니다.
- 셔플은 현재 곡을 유지하고 나머지 곡 순서를 섞습니다. 해제하면 원래 순서를 복원합니다. YouTube 목록 변경 검사 때문에 셔플이나 드래그 순서가 초기화되지 않습니다.
- 대각선 화살표 버튼으로 영상만 보이는 전체 화면 모드에 진입할 수 있습니다.
- 업로더가 외부 재생을 막은 영상은 YouTube에서 열기 버튼으로 전환할 수 있습니다.
- 핀 버튼으로 창을 다른 앱보다 위에 고정할 수 있습니다.
- 바이닐과 톤암을 모티프로 제작한 Needle 전용 macOS 앱 아이콘을 포함합니다.

## YouTube 로그인

오른쪽 위 사람 아이콘에서 연결합니다. 로그인하면 해당 채널에서 **직접 만든 재생목록**을 자동으로 불러오고, 목록을 누르면 플레이어에서 엽니다. 다른 채널에서 저장한 목록이나 YouTube 보관함 전체를 가져오는 기능은 아닙니다.

로그인 후 하단 링크 입력란 위의 **내 재생목록** 버튼으로 목록을 펼치거나 접습니다. 위로 열리는 목록은 스크롤할 수 있고, 현재 재생목록은 체크 표시로 구분됩니다. 목록을 선택하면 자동으로 닫히며, 현재 목록을 다시 선택해도 재생 위치는 초기화되지 않습니다. 바깥 클릭·닫기 버튼·Esc로도 접을 수 있습니다. 열 때 목록을 갱신하며 수동 새로고침도 지원합니다. 계정 관리와 로그아웃은 기존 상단 사람 아이콘에서 합니다.

설정이 포함된 배포본에서는 **Google로 로그인**을 누르고 기본 브라우저의 Google 화면에서 계정과 읽기 권한을 승인하면 됩니다. 다운로드한 사용자가 Google Cloud 프로젝트를 만들거나 JSON 파일을 가져올 필요는 없습니다.

로그인 토큰과 수동으로 가져온 개발자 설정은 macOS 키체인에 저장합니다. 비밀번호를 Needle에서 입력하지 않습니다. 로그아웃은 이 Mac의 토큰과 계정 목록을 지웁니다. Google 계정 자체의 앱 연결까지 취소하려면 Google 계정의 서드 파티 연결 관리에서 해제해야 합니다.

로그인은 목록 조회를 위한 것으로 내장 YouTube 플레이어의 로그인이나 Premium 이용 상태를 대신하지 않습니다. 비공개 목록·영상, 연령 제한, 외부 재생 금지 영상은 재생이 제한될 수 있습니다. 외부 앱의 OAuth 테스트 모드에서는 Google 정책에 따라 다시 로그인해야 할 수 있습니다(일반적으로 갱신 토큰 7일).

## 개발자용 Google 로그인 배포 설정

0.14.0에는 Needle용 실제 Desktop OAuth 설정(`GoogleOAuth.json`)이 포함되어 있습니다. Google Cloud 앱 등록과 YouTube Data API v3 활성화는 완료했으며, 현재 Google 앱은 **테스트 상태**입니다. 등록된 테스트 사용자만 로그인할 수 있고, 공개 배포 검증은 아직 완료되지 않았습니다. 설정 없는 개발 빌드는 로그인 버튼 대신 미설정 상태를 표시합니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 Needle용 프로젝트에 **YouTube Data API v3**를 사용 설정하고 앱 정보·대상 사용자를 설정합니다. 테스트 상태라면 테스트 사용자를 등록합니다. 요청 범위는 `https://www.googleapis.com/auth/youtube.readonly`입니다.
2. Needle용 OAuth 클라이언트를 **데스크톱 앱** 유형으로 등록하고 다운로드한 JSON을 `Sources/Needle/Resources/GoogleOAuth.json`에 둡니다. `installed` 형식의 실제 Desktop 설정만 사용합니다. 사용자 토큰, 서비스 계정 키, 웹 앱 설정은 포함하지 않습니다. Desktop 앱의 클라이언트 정보는 배포 가능한 공개 클라이언트 설정이며 사용자 로그인 토큰과 다릅니다.
3. 빌드 시 기존 SwiftPM 리소스 처리와 macOS 패키징이 해당 파일을 `Needle_Needle.bundle`에 포함합니다. 앱은 실행 중인 패키지의 리소스 번들을 우선 조회합니다. 실제 설정을 넣은 뒤 빌드·패키징하고, 깨끗한 사용자 환경에서 로그인, 목록 조회, 재실행, 로그아웃을 확인합니다.
4. 공개 배포 전에 [Google 민감한 범위 검증 요건](https://developers.google.com/identity/protocols/oauth2/production-readiness/sensitive-scope-verification)의 홈페이지·개인정보처리방침·도메인 소유권·범위 사용 증빙을 준비합니다. 기존 플레이어의 크롭·오버레이·숨겨진 보조 플레이어도 [YouTube 개발자 정책 III.I](https://developers.google.com/youtube/terms/developer-policies)에 맞는지 검토해야 합니다. OAuth 클라이언트 등록만으로 공개 배포나 정책 적합성이 승인되는 것은 아닙니다.

번들 설정이 없으면 이전에 가져온 키체인 설정을 그대로 사용합니다. 수동 개발 설정은 계정 화면의 접힌 **개발자 설정**에서 가져오거나 교체할 수 있습니다. 번들 설정은 수동 설정보다 우선하며, 잘못된 번들 파일이 있으면 다른 클라이언트로 조용히 전환하지 않고 오류를 표시합니다.

저장된 토큰은 발급받은 클라이언트 ID가 현재 설정과 일치할 때만 복원합니다. 클라이언트가 바뀌거나 이전 버전 토큰에 발급 클라이언트 정보가 없으면 토큰을 지우고 다시 로그인하도록 안내합니다.

참고: [Google 데스크톱 OAuth](https://developers.google.com/identity/protocols/oauth2/native-app), [내 채널 재생목록 API](https://developers.google.com/youtube/v3/docs/playlists/list).

## 자체 검사

```sh
SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk swift run --build-system native --disable-sandbox NeedleCheck
node Checks/player-check.cjs
node Checks/player-runtime-check.cjs
```

SDK 경로는 설치 환경에 맞게 조정합니다. 제공된 빌드 스크립트는 이 Mac의 CLT 27.0 SDK에 누락된 SwiftUI 매크로 플러그인을 피하기 위해 설치된 26.5 SDK를 선택합니다.

## iPad 확장 상태

SwiftUI 화면, URL 파서와 YouTube 플레이어는 iPadOS 17 코드 경로를 포함합니다. 실제 iPad 설치본을 만들려면 Xcode의 iOS 앱 타깃과 Apple 개발자 서명이 추가로 필요합니다. 이번 Google 로그인은 macOS 데스크톱 전용이며 iPad에는 별도 iOS OAuth 흐름이 필요합니다.
